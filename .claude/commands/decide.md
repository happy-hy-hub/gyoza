# /decide — 決定の記録

決定内容: **$ARGUMENTS**

これは**人間が下した裁定の記録作業**である。内容を再検討・再交渉してはならない。

## 手順

### 1. 採番する
`docs/requirements/decisions/` を Glob し、既存 ADR の最大番号 +1 を採る。
初回は `ADR-001`。番号は**3桁ゼロ埋め**。

### 2. ADR を書く
`docs/requirements/decisions/ADR-NNN-<英小文字ケバブの短い件名>.md` を作成する。

```markdown
# ADR-NNN: <件名>

- 日付: <YYYY-MM-DD>
- 状態: 採択 | 保留

## 論点
<何を決めようとしたか。1〜3行>

## 決定
<何に決まったか。断定形で書く>

## 理由
<なぜそれを選んだか。人間の裁定理由と、会議で出た支持根拠>

## 却下した案とその理由
- <案>: <却下理由>
- <案>: <却下理由>

## 影響範囲
<この決定が縛るもの。後続の設計・実装・他の論点への波及>
```

3ラウンド収束せず保留となった論点も、**状態を「保留」として同じ形式で残す**。

### 3. open-questions.md を更新する
`docs/requirements/open-questions.md` に対し:
- 決着した論点を**解決済みに移し、ADR 番号を添える**
- この決定から**派生した新論点があれば追加する**（優先度順の位置に挿入）
- 決定によって**不要になった論点は削除し、削除理由を1行残す**

### 4. 報告する
作成した ADR のパスと、open-questions.md の残件数を報告する。
残件が 0 なら `/spec` の実行を提案する。
